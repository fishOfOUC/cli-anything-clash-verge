# CLASH_VERGE.md

Software analysis for **Clash Verge Rev** — the basis for
`cli-anything-clash-verge`.

## 1. Software Overview

**Clash Verge Rev** is an open-source, cross-desktop GUI client for the
**Mihomo (Clash Meta)** proxy core, built with Tauri 2 (Rust) and React.

- Repository: <https://github.com/clash-verge-rev/clash-verge-rev>
- Product name: `Clash Verge`; sidecar core binary: `verge-mihomo`
- App id: `io.github.clash-verge-rev.clash-verge-rev`

It is a **GUI wrapper, not a proxy**. All packet handling, rule matching,
DNS and tunnelling are performed by the mihomo core. Clash Verge's own jobs are:

1. downloading and validating subscription profiles,
2. merging a selected profile with the user's overrides into a runtime config,
3. starting and supervising the `verge-mihomo` sidecar,
4. toggling OS-level system proxy and TUN mode,
5. rendering a dashboard and proxy switcher.

### Why CLI-ify it

Clash Verge ships **no CLI at all**:

- `src-tauri/src/main.rs` never touches `std::env::args()`.
- No `[[bin]]` target exists in any `Cargo.toml`; there is no `src-tauri/src/bin/`.
- No argument parser is linked (no `clap`, `structopt`, `argh`, `pico-args`).
- `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]` hides the
  console entirely in release builds.

The only argv read in the whole codebase is in
`src-tauri/src/utils/server.rs`, and it exists to forward a `clash://` deep
link to the already-running instance:

```rust
let request = if let Some(arg) = std::env::args().nth(1).as_deref() {
    if arg.starts_with("clash:") {
        client.get(format!("http://127.0.0.1:{}/commands/scheme", record.port))
              .query(&[("param", arg)])
    } else {
        client.get(format!("http://127.0.0.1:{}/commands/visible", record.port))
    }
}
```

Everything else is only reachable by clicking.

## 2. What the CLI reuses (no reimplementation)

The harness drives the *same* backends the GUI drives. Nothing about proxying,
rule matching or encryption is reimplemented.

### 2.1 Clash Verge's state files

Resolved by `src-tauri/src/utils/dirs.rs`:

```rust
pub static APP_ID: &str = "io.github.clash-verge-rev.clash-verge-rev";
pub static CLASH_CONFIG: &str = "config.yaml";
pub static VERGE_CONFIG: &str = "verge.yaml";
pub static PROFILE_YAML: &str = "profiles.yaml";
pub fn app_profiles_dir() -> Result<PathBuf> { app_home_dir().join("profiles") }
```

`app_home_dir()` is `<Tauri data_dir>/<APP_ID>`, or
`<exe_dir>/.config/<APP_ID>` in portable mode. Tauri's `data_dir()` is
`%APPDATA%` on Windows, `~/Library/Application Support` on macOS and
`$XDG_DATA_HOME` (or `~/.local/share`) on Linux.

### 2.2 The Mihomo External Controller

Clash Verge reaches the core through `tauri-plugin-mihomo`, configured with
`Protocol::LocalSocket` — a private IPC channel (Unix socket on Unix, named pipe
on Windows), *not* HTTP:

```rust
.plugin(tauri_plugin_mihomo::Builder::new().protocol(Protocol::LocalSocket).build())
```

The HTTP controller is a separate, opt-in surface, governed by
`verge.yaml`'s `enable_external_controller` (default `false`). When it is off,
Clash Verge blanks the `external-controller` address and keeps the core on IPC.
When on, the core serves the standard Mihomo External Controller REST API on
`127.0.0.1:9097` (`constants::network::DEFAULT_EXTERNAL_CONTROLLER`), guarded by
`config.yaml`'s `secret` (default `set-your-secret`).

`cli-anything-clash-verge controller enable` flips that flag; the CLI then
speaks exactly the endpoints the Tauri shell speaks, over HTTP.

## 3. Data model

### 3.1 `profiles.yaml` — `IProfiles` / `PrfItem`

```rust
pub struct IProfiles {
    pub current: Option<String>,
    pub items: Option<Vec<PrfItem>>,
}

pub struct PrfItem {
    pub uid: Option<String>,
    #[serde(rename = "type")] pub itype: Option<String>,  // remote|local|script|merge|rules|proxies|groups
    pub name: Option<String>,
    pub file: Option<String>,
    pub desc: Option<String>,
    pub url: Option<String>,
    pub selected: Option<Vec<PrfSelected>>,
    pub extra: Option<PrfExtra>,      // upload/download/total/expire
    pub updated: Option<usize>,       // unix seconds
    pub option: Option<PrfOption>,
    pub home: Option<String>,
}
```

`uid` prefixes encode the type — `R` remote, `L` local, `s` script, `m` merge,
`r` rules, `p` proxies, `g` groups — generated by `help::get_uid` as
`<prefix> + nanoid(11)`. The profile-data-file regex only accepts
`[RLmrpg][a-zA-Z0-9]+\.yaml` (or `s…\.js`), so the uid body is alphanumeric.

**Companion items are mandatory.** Every real profile is surrounded by five
companions named `<uid> merge`, `<uid> script`, `<uid> rules`, `<uid> proxies`,
`<uid> groups`, seeded from `src-tauri/src/utils/tmpl.rs`. `profile import` and
`profile create` write all six, with the templates copied verbatim.

### 3.2 `verge.yaml` — `IVerge`

Application settings: theme, tray, system proxy and TUN toggles, inbound ports
(`verge_mixed_port`, `verge_socks_port`, `verge_port`, `verge_redir_port`,
`verge_tproxy_port`), autostart, hotkeys, backup schedule, and
`enable_external_controller`. 75+ fields, all `Option<…>` and omitted when
unset.

**`webdav_url`, `webdav_username` and `webdav_password` are persisted with
`serialize_encrypted` / `deserialize_encrypted`.** Writing plaintext back would
corrupt them, so the CLI refuses to set those three keys.

### 3.3 `config.yaml` — `IClashTemp`

A free-form `serde_yaml_ng::Mapping` holding Clash core overrides. Defaults come
from `IClashTemp::template()` and `constants::network::ports`:

| Key | Default |
|-----|---------|
| `mixed-port` | 7897 |
| `socks-port` | 7898 |
| `port` | 7899 |
| `redir-port` | 7895 |
| `tproxy-port` | 7896 |
| `mode` | `rule` |
| `log-level` | `info` |
| `ipv6` | `true` |
| `external-controller` | `127.0.0.1:9097` |
| `secret` | `set-your-secret` |
| `unified-delay` | `true` |

### 3.4 `clash-verge.yaml`

The **generated** runtime config — profile + enhancement + `config.yaml`
merged. This is what mihomo actually loaded, so the CLI treats it as the
authoritative source for "what is running right now" (`env info`,
`core status`).

## 4. Why not 1:1 GUI parity

Clash Verge's UI exposes roughly 83 `#[tauri::command]` handlers. Many of them
cannot be reproduced from outside:

- **System proxy and TUN toggling** write OS state (Windows registry / network
  settings, macOS `networksetup`, Linux sysctl + routing) and, for TUN, require
  the elevated `clash-verge-service`. From a CLI these are just two booleans in
  `verge.yaml` — the CLI sets them accurately, but only the app (or a restart)
  can apply them.
- **Anything requiring a core restart** (switching the active profile, changing
  ports, enabling the HTTP controller) has no external trigger. The CLI writes
  the state and says so; `session undo` is available if that was a mistake.
- **Live restart / reload** endpoints do not exist. The single-instance server
  only offers `/commands/visible`, `/commands/scheme` and `/commands/pac`.

Rather than fake these, the harness states the limitation and routes the caller
to the live controller wherever a live path exists.

## 5. Write-race protection

Clash Verge holds its configuration in memory and rewrites the YAML whenever
the user changes something, and it has **no file watcher**. An external edit
while the app runs is therefore invisible at best and silently reverted at
worst.

Every mutating command goes through a single guard:

```
Error: Clash Verge is running and owns its configuration files.
Editing them now risks your change being silently reverted by the app.
Either: close Clash Verge and retry,
     or: use the live commands (proxy/mode/conn) which go through the controller,
     or: pass --force to write anyway.
```

## 6. Session and undo

There is no project file — Clash Verge's home directory *is* the project. The
session (`~/.cli-anything-clash-verge/session.json`, written under an exclusive
lock with stale-lock reclamation) remembers the target directory plus controller
overrides.

Every mutation records the exact bytes of each file it touched, before and
after. `session undo` restores the "before" bytes; a file that did not exist
before is deleted. This makes agent-driven editing reversible across separate
CLI invocations.

## 7. Test results

```
193 passed in 20.24s
```

- 129 unit tests: path resolution, YAML round-tripping, session/undo, schema
  coercion, profile store, subscription validation, controller client, process
  helpers.
- 64 end-to-end tests: the real CLI through `CliRunner`, asserting on exit
  codes, emitted JSON and bytes on disk. The mihomo controller is replaced by a
  real HTTP server on a loopback port, so URL construction, Bearer auth and JSON
  decoding are genuinely exercised.

No Clash Verge installation and no network access are required.
